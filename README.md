# PhonePe Pulse Data Analysis | Power BI

## Project Overview

This project focuses on analyzing PhonePe transaction data across India using Microsoft Power BI.

The dashboard provides insights into digital payment trends, transaction volumes, transaction values, and geographical patterns.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## Key Objectives

* Analyze transaction trends across different years and quarters.
* Understand state-wise transaction performance.
* Identify patterns in digital payment adoption.
* Explore user and insurance-related trends (where included in the dashboard).

## Project File

Download the Power BI dashboard:

`PhonePe_Pulse_Analysis.pbix`
